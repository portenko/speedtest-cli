# speedtest-cli

Консольный скрипт на Python 3.8+. Без зависимостей, только стандартная библиотека.
Делает 10 последовательных запросов к адресу, ждёт полного ответа на каждый,
считает среднее время и объём данных, печатает скорость скачивания.

## Запуск

```bash
python3 speedtest.py                      # файл 5 МБ от Cloudflare по умолчанию
python3 speedtest.py https://example.com/big.jpg
python3 speedtest.py URL -n 5 -t 10       # 5 запросов, таймаут 10 с
```

## Единицы измерения

- время: секунды (с);
- объём: мегабайты, 1 МБ = 1 000 000 байт;
- скорость: МБ/с и Мбит/с (1 байт = 8 бит), считается как весь объём / суммарное время запросов.

## Заметки

- Ответ читается кусками по 64 КБ, память не растёт на больших файлах.
- Время запроса: от отправки до последнего байта тела.
- Ошибочный запрос выводится в stderr и не входит в среднее. Код выхода 1, если не прошёл ни один.
